# Career OS

Most resumes describe where someone has worked.

This project explores a different question:

How can AI help communicate a person's career the same way a great product communicates itself?

This repository contains:

- A master career narrative
- Resume generation pipeline
- Product case studies
- Interview story database
- Prompt engineering
- Design system
- Website source
- Resume rendering engine

Rather than treating a resume as a static document, I treat it as a compiled artifact generated from a structured knowledge base.

Future outputs include:

- Resume
- Website
- LinkedIn
- Cover letters
- Interview preparation
- Conference bios
- Personal brand assets
